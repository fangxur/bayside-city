# 湾畔市 · Bayside City

一款可在本地浏览器中游玩的 3D 城市建设原型：铺路、规划住宅与工商分区、接通水电，经营一座逐渐生长的河湾小城。游客可单机游玩，也可登录账号统一管理单人城市和合作城市。

本项目以 [MIT 许可证](LICENSE) 开源。前端使用 Three.js，后端使用 Node.js 内置 HTTP 服务与 SQLite，支持自定义地图、不同风格建筑、昼夜景观、城市存档与好友共建。

## 启动

服务器需要 Node.js 24 或更高版本和 npm；电脑或手机使用支持 WebGL 2 的浏览器访问。

```sh
git clone https://github.com/fangxur/bayside-city.git
cd bayside-city
npm ci
npm start
```

打开 [http://127.0.0.1:4173](http://127.0.0.1:4173)。服务仅监听本机；依赖安装完成后，运行游戏无需连接外部服务。

## 开始玩

- **从零建设**：获得 30,000 启动资金。从西侧入口延伸道路，在路边放置供电站与水塔，再划出住宅、商业和工业分区。建筑只会在连接入口的临路地块上自动生长。
- **先编辑地图**：新建城市时选择「编辑地图」，在正式建城前自由绘制陆地、水域与树林，支持不同笔刷、撤销、重做和 3D 预览。单人和合作城市都可以使用自定义地形。
- **体验示范城**：接手已有居民、商店、工坊和公共设施的小镇，可立即尝试扩建、交通改造与财政调整。
- **继续上次的城市**：已有本地存档时出现在欢迎界面；具体检查点也可从右上角菜单读取。
- **导入城市存档**：开始页、新建城市页和单人存档菜单均可选择 JSON 文件，先核对城市名称、人口、地图大小、建筑数量与资金，再创建独立的新城。支持原始导出、紧凑存档和包含 `city` 的检查点文件；损坏文件会在创建前被拦截。游客导入为本地单人城市，登录后可保存为新的账号单人城市，或创建由自己担任房主的合作城市。合作大厅也提供“从存档创建合作城市”入口。地图、建筑、资金和城市目标沿用原存档，旧账号城市的身份不会从文件继承；切换前先保存当前单人城市，导入后的单人城默认暂停。

将陆地道路接到地图任一边缘、并接通向内的道路，即可增设对外入口。相邻边缘车道组成同一个宽入口，每格保留自己的道路容量；孤立边缘地块和水面不能形成入口。企业货运按实际路程、道路等级和拥堵选择入口，大批货运可分批走不同路线。城市概览显示入口数量和各入口货运负荷，点击入口列表可定位、查看详情和升级道路。旧存档自动识别现有边缘道路；撤销、拆除、移动和合作城市使用相同规则。居民通勤仍沿真实相连的城内道路行驶。

车辆靠右行驶，并从建筑所在一侧的车道进出。到达对面建筑需要经路口绕行，双黄线及宽道路中央分隔区不能作为捷径；可在路口或道路尽头掉头，立交桥内保持直行。通勤、货运、公交与公共服务车辆分别规划合法的去程和回程，路口以弧线转弯，夜间车灯随车头一起转向。交通负荷计入往返实际经过的道路；八格道路以内的短途通勤采用步行，不产生汽车车流；行人沿外侧人行道行走，过街会先绕到路口斑马线，宽道路横跨完整路幅；回程沿同一路线返回，道路尽头可沿人行道绕行，不穿过车道。

从零开局会打开八步建城引导：连通道路、供电、供水、规划住宅、等待入住、准备岗位与货源、开店、认识街坊。桌面和手机都有常驻的当前任务卡；按钮会展开并高亮具体的二级工具，同时定位地图推荐位置；完成当前建设步骤后退出放置工具，减少误建。地图光框提供按实际地形、道路和空地计算的推荐位置，不会自动建设。步骤依据真实连通和运行状态完成，已有建设可直接跳过；住宅规划后自动以 3 倍速等待施工和入住，后续引导连续运行；顶部手动暂停或调速优先，不再每步要求继续模拟。手机默认显示简短任务，点“说明”展开详情，菜单打开时卡片进一步收起，定位避开实际面板位置。施工会显示进度，断路、停用、缺水电或需求不足会提示定位原因。

单人引导在道路、水电规划阶段暂停时间；规划住宅后自动运行并加速，后续建设无需逐项确认继续模拟。手动使用顶部时间控制后，引导尊重玩家选择；合作城市不自动改变共用时间。可随时跳过，在市长手册中重新打开；本机检查点保留跳过和居民交流记录，普通城市存档格式不变，旧城市按现有建设推导步骤。

桥梁没有人口门槛：点击河面或紧邻的岸边，两岸有陆地落点、无建筑阻挡且资金至少 ¥3,500，即可建设整段跨河桥梁；建好后需接入道路网络。道路升级只跟人口走：达到 1,000 / 5,000 / 10,000 / 20,000 / 50,000 / 60,000 人后，分别永久开放二至七级道路，不要求市政府或领域协同。住商工、水电和公共设施仍按各自城市阶段与服务条件解锁；达到 2,000 人、满意度至少 70%，并连续三个模拟月收支非负，即可解锁地标和其他市政设施二级升级。

两个方向道路均不少于三格宽的十字路口支持立交设计，包括 3×3、4×4、5×5 和 3×5 等矩形路口。选择「查看」点击路口任意一格，在路口详情的「立交设计」中选择南北高架 / 东西地面，或东西高架 / 南北地面。选择后先打开独立的 3D 模拟，可对比原路口、改造预览，旋转视角并查看交通图层；模拟会提示失去对外连接的建筑数量，确认后才施工扣款，取消不改变城市与撤销记录。四个方向须连接同宽陆地道路，高架两端各留两格坡道和一格平路接头。新建 ¥6,000，改变高架方向 ¥1,000，额外月维护 ¥90；可免费恢复平面路口，保留道路。两层车辆分别直行，路口内不转弯、不设红绿灯，跨方向通勤和公共车辆会沿外围路网绕行；坡道不能直接作为建筑出入口。桥面与坡道保留交通热力颜色，路口详情显示高峰负荷、容量与拥堵程度。交通数值沿用每格道路的合计负荷。方向与宽度支持存档、撤销和合作城市同步。

立交预览沿用当前地图视角，路口固定居中，随预览区域大小和旋转角度自动调整比例，完整容纳桥面与坡道。拖动旋转、滚轮或双指缩放围绕路口中心进行，「居中路口」可恢复完整视图。选中路口与预览时，在道路上显示东、西、南、北标记，并区分高架和地面；旋转视角只改变标记的屏幕位置，不改变地图方位。对比原路口时，标记随原路口实际结构更新。

在“市政服务 → 基础保障”中，可选择原有 1×1 水电设施或新增 2×2 大型设施。大型供电站造价 ¥10,000、一级容量 3,000、月维护 ¥600；大型供水站造价 ¥6,000、一级容量 3,600、月维护 ¥320。大型设施需要连续四格陆地空地，任一边临路即可整体建设；各等级容量、升级费和维护费均为小型设施的 4 倍，移动、旋转、拆除和存档均按完整 2×2 处理。旧存档中的 1×1 设施保持原样。

供电站和水塔均可升至六级：完成 1,000 / 5,000 / 10,000 / 20,000 / 50,000 人城市阶段后，依次解锁二至六级，沿用各阶段的市政条件。选择“查看”或“升级”后点击设施，也可在电力 / 供水建设模式点击对应的已有设施，查看容量、费用、维护变化并升级。改造期间保持原等级容量，完工后启用新容量；占地不变，暂停或断开道路仍会停止供应。供电容量逐级为 750 / 1,600 / 3,200 / 6,000 / 9,900 / 15,600，供水容量为 900 / 2,000 / 4,000 / 7,500 / 12,375 / 19,500。

## 警察局与公交

在「市政服务 → 城市治理」建设警察局（1×1，¥3,000，月维护 ¥150）。完成施工并接通对外道路、水电后，沿道路 14 格提供治安覆盖，覆盖住宅满意度 +3；随六级升级扩展范围。治安覆盖按居民人口降低抢劫风险（全覆盖时降低 70%），并将覆盖住宅受到的抢劫事件满意度与迁出影响减半。警车平时沿真实道路巡逻，抢劫时前往事发建筑；稳定就业仍有助于预防抢劫。

在「市政服务 → 公共交通」建设公交站（1×1，¥800，月维护 ¥60，无需升级）。至少两个站完成施工、接通同一道路网络和水电后，自动开通往返公交。住宅与岗位分别位于不同的运营站点 4 格范围内、道路通勤至少 4 格时，该通勤车流减少 40%，计算的通勤时间减少 15%；公交车同样遵守路口信号。单个站点尚未开通服务，暂停、断路、缺水电或拆除后会重新计算线路和效益。点击站点可查看线路数量与全城公交通勤人数。

两类设施支持移动、旋转、暂停、拆除、撤销，以及单人和合作城市存档。

手机可以直接竖屏游玩。底部建设工具左右滑动，道路后依次是市政服务、工业、住宅、商业；点击分类打开可滚动的建设菜单。城市与详情面板默认收起，点上方按钮展开；图层、缩放和旋转在下方的“图层”“视角”中。查看模式下单指拖动地图，双指捏合可围绕两指中心连续放大、缩小并平移；点建筑查看详情。选中建设工具后点地图放置或拖动施工，第二根手指落下会取消当前施工预览并进入缩放，避免误建。功能面板随屏幕宽高调整，较长的登录表单和其他弹窗在内部滚动；横竖屏切换无需重新进入城市。

手机顶栏右侧的向上箭头可收起整个顶栏，左上角“展开顶栏”可恢复资金、人口、账号和速度控制。右上角“需求 · 水电”小看板集中显示三类分区需求和水电已用 / 总容量；点击标题可独立折叠。两种折叠偏好都保存在当前浏览器。打开建设菜单、城市详情或地图控制时，看板临时收成标题，关闭后恢复之前的状态；点击住宅、商业需求可高亮对应建筑，点击工业需求会同时保留工业、供电与供水设施，升级模式下也会显示三者可用的升级箭头和价格。

## 已实现的系统

街头见闻：每位行人有固定的姓名、住宅和生活爱好，职业来自住宅实际分配到的工作地点；日常小故事会随模拟时间变化。居民会去上班、和街坊约会、参加附近活动、买东西、散步，也会沿原路回家。节日期间，一部分居民会优先前往实际开放且道路可达的节日场所；圣诞节会去喝热饮、挑选小礼物、看灯饰或参加聚会。点击行人或“街头见闻”，在出行卡片选择“在地图上看路线”，可查看起终点、方向、预计用时及拥堵路段，并切换去程 / 回家路线。通勤沿用实际岗位分配，其他出行通过人行道与斑马线寻路，地图路线与行人实际轨迹一致，支持桥梁和大建筑入口；没有可达目的地时不会画出穿过空地的假路线。修路、拆除、停业和读档后会按当前城市重新计算，查看故事不消耗城市资金或改变随机数。

- 支持标准 64 × 64、大型 80 × 80、超大型 96 × 96 三种地图；常规规划人口参考分别约为 6 万、6–10 万和 10 万以上，参考值并非硬上限。包含道路连接、按两岸落点与占用条件自由选址的跨河桥梁，以及住宅、商业、工业分区的需求与施工成长。
- 居民迁入迁出、岗位分配、通勤路径与拥堵；道路升级和新增连接会影响路网负荷。
- 全城水电容量、工业与供电站污染、公园和广场的环境加成、满意度及诊断信息。公园与广场不要求道路、水电连接，在空地上分别向半径 5 格、8 格提供环境加成，暂停后停止加成。
- 相邻并排的直路自动呈现连续宽路面，信号灯只保留在真正接入支路的路口；同类公园或广场摆成 2×2 后自动呈现大型整体款式，拆除后重新识别。原有逐格建设、维护和存档规则保持兼容。
- 月度税收与维护费、可调税率、设施暂停、一次应急贷款，以及 500、1,000、2,000、5,000、10,000 人的成长路线。
- 就业与行业看板按医生与医护、消防员、教师与教职工、政府工作人员、水电运维、公共文化和体育人员列出事业单位编制与实际在岗人数；商业与工业按具体业态列出场所、实际到岗、岗位、经营税和企业工资，文化娱乐与休闲另列演艺、社区、园林和景点人员。停运或失去道路、水电的公共设施不计在岗，所有税收和工资与当月财政口径一致。
- 道路在 1,000 / 5,000 / 10,000 / 20,000 / 50,000 / 60,000 人时依次永久开放二至七级，只看人口，不受市政府、盈利、满意度或领域协同影响。跨过 5,000、10,000、20,000、50,000 人节点会立即暂停并显示里程碑庆典，关闭庆典后居民走上街头、礼花持续约 24 秒；领域协同稍后完成时不会重复人口庆典。1,000 人且市政府正常办公后开放住宅、商业、工业、供电站和水塔二级升级；完成 2,000 人阶段（满意度 ≥70%、连续盈利三个月）开放消防站、市政府与其他公共设施二级升级。三级及以上建筑采用领域协同晋级，需要让上一等级的道路、水电、住商工和公共服务实际运行，并达到相应覆盖、交通畅通及低污染比例。成长目标逐项显示实时缺口；阶段达成后永久保留。
- 新建单人城市与合作城市先选择城市规模，再从该规模对应的三项长期目标中确认一项。标准地图目标为 50,000 人、荣誉 Lv.8、或 30,000 人且满意度 90%；大型地图提高到 80,000 人、Lv.10、或 60,000 人且满意度 91%；超大型地图提高到 120,000 人、Lv.12、或 100,000 人且满意度 92%。切换规模会清空此前选定的目标，避免目标与地图不匹配。目标独立于逐级城市成长任务，随存档保存，并在城市成长面板持续显示实时进度与达成月份；旧存档按自身地图规模采用人口目标。
- 消防站每升一级增加 3 格道路覆盖，正常运转的市政厅每升一级为全城消防站增加 2 格调度范围。移动消防站或演练目标会中止相关演练；撤销搬迁可恢复原状态。
- 交通、电力、供水、污染图层，建筑检查面板、建设预览与费用提示。
- 左侧「城市图鉴」汇总当前版本的全部建筑与车辆，按住宅、商业、工业、市政、宗教、景观、名胜及交通类型筛选，并随人口、城市阶段、产业链和公共设施实时标记已解锁与未解锁条件。点击任意条目会使用地图中的实际模型打开独立三维展示台；普通可升级建筑能在左上角切换 1–6 级外观，名胜可切换 1–3 级，镜头会按高度自动取景，装饰则标记为「固定外观」。建筑和道路车辆都只展示主体，不附带门前或车底道路；道路车辆会居中放大，游艇保留水面环境。可拖动或点击按钮逐步旋转，并使用放大、缩小按钮或滚轮调整模型大小；查看图鉴不会修改城市和存档。手机端采用单列目录，标题、关闭按钮和建筑/车辆切换形成连续吸顶栏，解锁数量改为紧凑行，滚动时不会残留空白色块。
- 沿街车流随人口阶段扩展为城市轿车、微型车、掀背车、越野车、出租车、多用途车、皮卡、厢式配送车和货车；不同车型使用独立车身比例、车顶附件、配色与载货轮廓。正常运转的消防站、诊所与医院会派出重新设计的消防车和救护车，以车顶梯架、红十字、侧面识别带和红蓝警灯形成清晰区分；发生火灾或医疗事件时沿真实道路赶往现场，平时在服务街区巡行并遵守红绿灯与排队规则。点击普通车辆可听到与拥堵、污染、水电、就业等实际情况有关的街头故事，并跳转到相关地段处理问题。居民住宅平均通勤达到 15 分钟后，才会因局部高负载道路抱怨拥堵；短途通勤仍可在详情中查看道路负载，但不会被描述成堵车。
- 城市风险事件按真实状态在月结时判定：200 人后高失业可能出现抢劫，500 人后消防覆盖不足或医疗缺口可能引发失火、医疗挤兑；800 / 2,000 / 3,000 人后依次检查教育、文化和体育缺口。全城同一时间最多发生一件，事件结束后至少保留恢复期，同类事件一年内不会重复。事件会定位到受影响建筑，降低周边满意度、入住意愿和住宅需求；失火还会暂时降低目标企业效率或阻止目标住宅入住，并按建筑实际高度显示动态分层火舌、上升烟雾、余烬和暖光。补足岗位或对应服务覆盖会降低之后的风险，当前事件与历史记录随存档保存。
- 社区集市小事件：花费 300 城市资金，让满意度在当前及下一模拟月增加 4 点；活动期间不能叠加，效果与举办记录随城市存档保存。
- 陆地三岔与十字路口自动设置信号灯，南北和东西方向交替绿灯、黄灯和全红清空；车辆在停止线前排队，绿灯后依次通过。暂停与 3× 速度同时作用于信号灯和路上角色。
- 消防站（2,200）与全城唯一的市政府（3,000）：需要道路、水电和正常启用。消防站按真实道路距离覆盖住宅，受覆盖住宅满意度增加 2 点；市政府开放市政方针、住宅市政覆盖、消防预算与安全演练。
- 市政府提供三种可随时切换的市政方针：「均衡治理」使覆盖住宅满意度 +2；「民生优先」使覆盖住宅满意度 +4，同时公共设施运行与工资支出 +12%；「招商促进」使商业、工业需求 +10、企业经营税 +8%，覆盖住宅满意度 +1。市政府停运时方针暂停，合作城市由房主调整。
- 消防预算可选 70%、100%、130%，分别覆盖沿路 8、14、20 格，每站月维护为 84、120、156；市政府月维护 80。消防图层、建筑详情和政务面板实时显示服务覆盖，维护费用在月末统一结算。
- 每模拟月可免费组织一次消防演练：消防车沿道路出动、抵达并处置，镜头自动跟随；手动平移、旋转或缩放可自由观察。政务面板保留最近记录。道路被切断、站点失效或目标失去覆盖时会中止并说明原因。演练没有损伤、收费或奖励，进度与预算随存档保存。

## 存档

右上角菜单支持手动保存、读取、导出 JSON 和导入 JSON。游戏在月结、页面隐藏及离开时尝试自动保存，最多保留三个不同检查点；空间不足时会减少检查点数量。切换城市前若保存失败，会保留当前城市并提示导出。

城市名称和市长姓名各支持最多 24 个字符；市长可用昵称，也可留空。保存城市档案时会立即生成自动检查点，两项信息随存档保留，导出文件也会带上城市名称。旧存档仍可读取，未署名的市长显示为“尚未署名”。

游客存档保存在当前浏览器与站点地址的本地存储中。`localhost:4173`、`127.0.0.1:4173` 和其他端口各自拥有独立的游客存档；清理站点数据会删除本地存档。需要长期保留或迁移城市时，使用“导出存档”，或在首页、右上角及存档菜单打开“账号与我的城市”，登录后绑定已有游客城市。

登录后新建单人城市自动保存到当前账号；仍由本机模拟，定期同步到游戏服务器。其他设备登录同一服务器的同一账号即可继续。断网进度暂存本机，版本冲突不会覆盖服务器新进度；“我的城市”提供本机版本另存、服务器版本恢复和带二次确认的存档删除。删除正在游玩的账号单人城市后会回到开始界面；游客存档只从当前浏览器删除。合作城市也列在同一面板，只有房主能永久删除整座合作城市，绑定单人存档不会自动开放合作权限。

## 原型范围

这是城市建设玩法原型，支持游客单机、账号单人存档和好友合作，采用程序化建筑。居民按建筑聚合模拟，通勤与货运沿真实道路分配；画面中的车辆代表多次出行，并非每位居民独立驾驶。红绿灯控制可见车辆的停车和通行，宏观拥堵、通勤统计仍按路网负荷估算；行人目前沿街散步，没有独立的行人信号相位。水电沿连通道路提供全城容量，没有单独的管线；商业和工业使用简化需求、岗位与税收规则，没有完整商品供应链。

消防演练的车程按道路距离估算，消防车沿调度路线展示响应过程。火灾等城市风险事件会产生阶段性影响，但不会永久烧毁建筑；警察局沿道路提供治安覆盖并派出警车；公交站成对连通后自动开通往返公交，降低通勤车流。当前没有独立治安预算、地铁或自由绘制桥梁。重点是让道路、分区、服务、交通和财政形成可观察、可调整的建设循环。

「社区服务」新增学校、诊所、图书馆、体育馆。造价分别为 2,800 / 2,400 / 3,200 / 3,600，月维护为 100 / 120 / 90 / 140。完成建设且连接对外道路、水电并启用时，分别为半径 7 / 6 / 8 / 6 格内住宅提供 +3 / +4 / +2 / +3 满意度；同类不叠加，不同类型可叠加。图书馆同时提供文化与教育覆盖，可扩大学校教育服务的覆盖范围，但城市阶段仍需正式学校正常运行。诊所和综合医院在建筑正面、建设菜单与图鉴中统一使用红十字医疗标识，各等级均保留。可移动、暂停、拆除和保存，无新增人口解锁门槛。

公园与喷泉广场支持四级升级，1,000 / 5,000 / 10,000 人阶段解锁后续等级。公园每次升级 450 / 1,000 / 2,000，环境半径 5 / 6 / 8 / 10 格；喷泉广场升级 800 / 1,800 / 3,200，半径 8 / 9 / 11 / 13 格。维护费随等级增加；始终无需道路水电。2×2 组合绿地点击任一格即可升级整组，按各成员收费，大型外观按最低等级展示。

新建体育馆占地 2×2，包含主馆、室外球场和入口绿化。四格共同预览、占地、移动和拆除，只收一次造价；任意边缘临路均可连接。旧存档里的单格体育馆保留原尺寸，避免挤占周围建筑，新建时使用新版四格款式。

住宅升级现在同时检查阶段与服务：二升三级需要有效消防、医疗覆盖；三升四级继续要求消防、医疗，并需要公园覆盖、环境加成至少 12、污染不超过 20。喷泉或名胜不能单独替代公园条件。详情逐项显示是否满足，条件不足不扣款，不自动降级已有住宅。

选择功能建筑会高亮当前实际覆盖。医疗 6 格、学校 7 格、体育馆 6 格、图书馆 8 格；图书馆的范围同时计入文化和教育覆盖。公园与喷泉范围随等级变化。市政厅半径 10/12/14/16 格，范围内住宅满意度 +2，原有消防调度加成保留。消防沿连通道路按预算与等级计算；电力、供水使用连通网络与总容量，显示当前得到供应的地块。暂停或服务中断时覆盖立即重算；公园和喷泉仍无需道路水电。

使用“移动”工具搬迁功能建筑时，覆盖预览会跟随建筑幽灵实时移动：诊所、学校、图书馆、市政府等按当前等级显示目标半径，消防站按目标位置相邻的真实道路重新计算，组合绿地按整组新位置显示合并范围。拖动期间隐藏原址覆盖，取消移动后恢复，正式放置前不会修改城市状态。

点击电力、供水、污染、消防、医疗、教育、文化、体育、市政或休闲景观图层时，地图会用该领域颜色填亮所有对应建筑，并增加高对比立体边框、屋顶光环和浮动定位箭头；远景和手机小屏也能辨认。复合设施会出现在每个实际服务领域中，例如图书馆同时在教育和文化图层高亮。大型医院、体育场、美术馆、区政务中心以及景观装饰和名胜均按实际功能归类。覆盖地块仍只计算正常运行的设施，停运设施会保留建筑高亮，便于发现服务中断来源。

1 万人口是成长里程碑，不是人口上限。达成后目标每 5,000 人继续递增；实际发展仍受地图空间、供需与服务容量影响。超过 2,000 人后，需求中的数量差额按城市规模折算，避免绝对数量将大城市需求过度压低。需求面板只显示住宅、商业、工业三类需求与简短状态提示；准确计算仍在模拟内部执行，缺路、缺电、缺水等阻碍会通过建设提示和城市警报说明。

## 好友合作城市（第一版）

使用 Node.js 24 或更新版本启动 `npm start`，在欢迎页或城市菜单选择 **好友共建城市**。首次注册账号名和密码、填写玩家名字，可以创建空白合作城市、复制正在玩的单人城市，或使用房主发来的邀请加入。每座城市最多 4 位成员。

- 合作城市由服务器统一推进和保存，初始暂停；房主控制暂停、速度、税率与贷款。其他成员可以共同建设。
- 邀请链接先展示城市介绍，未登录的朋友可以选择“以游客身份游览”：自由移动视角、缩放、查看建筑与切换昼夜，城市画面每 5 秒读取最新进度。游客不创建身份、不占 4 人共建名额，也不推进或修改城市。想参加时点击“加入共建”，登录 / 注册后再确认加入；登录本身不会自动成为成员。满员城市仍可游览，邀请到期、被房主换新或因移除成员而失效后，会停止游览。游客访问仅凭有效邀请开放，不提供公开城市列表。
- 建设日志记录操作者、建设范围、实际费用和版本；可筛选、定位，并自动刷新。
- 每笔成功操作用 SQLite 事务一起保存城市、命令回执和日志。重复发送不会重复扣费，同地块冲突会提示重试。客户端每 1.5 秒拉取已确认的新状态。
- 断线期间只读，未确认请求保留原编号重连核对。无人连接超过约 10 秒后停止模拟，不补算离线时间。
- 菜单“保存城市”创建纪念存档；合作面板支持命名存档、导出、复制为新城市，以及房主恢复原城市。恢复前自动备份，恢复后暂停并切换分支。
- 自动检查点保留 24 份、每日存档 30 份；命名存档最多 50 份。命名/里程碑/恢复前快照不会被自动清理。
- 单人存档仍使用原本的浏览器本地存储，进入合作城市不会覆盖它。
- 合作城市按当前成员自动显示多位「合作市长」，房主排在前面；加入或移除后自动同步，离线成员仍保留署名。左上角、城市档案、城市政务和市政府详情使用同一名单；长名单可点击城市名称查看完整名字。合作署名不改变单人存档的市长姓名。
- 房主点击左上角城市名称，在城市档案顶部查看并复制邀请码或邀请链接；有效期为 24 小时，重复打开会复用同一有效邀请码。合作面板的「邀请好友」使用相同入口。普通共建成员需向房主获取邀请。局域网模式会将本机访问时的邀请链接自动改为电脑的局域网地址；移除成员后原邀请失效。

**连接朋友：** 默认只监听 `127.0.0.1:4173`，本机可打开多个页面测试。要让同一局域网的朋友加入，先停止原来的服务，再运行 `npm run start:lan`（等同于 `HOST=0.0.0.0 npm start`）。所有人连接同一局域网，通过运行游戏电脑的地址打开游戏，例如 `http://192.168.50.222:4173`，再生成邀请链接；localhost 链接无法在朋友电脑上使用。房主也可以继续使用原来的本机页面，把邀请链接中的 `127.0.0.1` 或 `localhost` 换成电脑的局域网 IP 后发给朋友，保留端口和 `#join=…` 邀请部分。同一服务器数据库下，换地址后登录相同账号即可找回成员身份。旧版临时身份应先在原地址绑定账号。公网使用需配置 HTTPS、稳定的服务器存储及相应运维保护。

**玩家账号：** 账号名＋密码登录，同一账号跨设备共享城市与权限；邀请码用于游览或加入朋友的城市，正式共建需要登录。旧玩家在原浏览器选择“绑定账号”，原 ID、房主权限和建设记录保留。登录使用 HttpOnly Cookie，可查看和撤销登录设备；忘记密码用注册时下载的恢复卡找回。详见 [账号、多设备与版本更新](docs/ACCOUNTS-AND-UPDATES.md)。

**服务器存档：** 默认路径 `.bayside-data/cities.sqlite`，可用 `COOP_DB=/绝对路径/cities.sqlite` 指定。数据库及其目录不经静态文件接口公开。运行中每 5 分钟用 SQLite backup API 创建经完整性检查的独立备份文件，保留最近 24 份；也可执行 `npm run backup:coop` 手动备份。`COOP_BACKUP_DIR` 可指定备份目录，建议另行复制到其他磁盘或远端存储。相同磁盘上的副本不能防止磁盘整体损坏。

恢复数据库文件时先停止服务，完整保留原数据库以及相邻 `-wal`、`-shm` 文件，再通过 `COOP_DB` 指向选定备份启动；不要运行中覆盖数据库文件。恢复较旧的整库备份后，先隔离旧客户端，由管理员核对遗漏进度和凭据，再重新开放连接。日常回退优先使用游戏内“恢复这座城市”，它会自动隔离旧分支请求。

设计与实现边界见 [合作存档与建设日志](docs/COOP-SAVES-AND-CITY-LOG.md)。

**宝塔部署：** 为 `city.yunyousl.com.cn` 准备了 [逐步部署说明](docs/BAOTA-DEPLOYMENT.md)、PM2 配置与 Nginx 代理片段（`deploy/baota/`）。在 HTTPS 反向代理后设置 `PUBLIC_ORIGIN=https://city.yunyousl.com.cn`，使请求来源校验使用浏览器实际访问的公开域名。未设置时保留本机 HTTP 用法。存档目录应通过 `COOP_DB` 配置在代码目录之外。

**版本更新：** `npm run release` 生成不含存档、环境变量或登录凭据的 tar.gz 发布包和 SHA256 校验文件。宝塔更新工具支持准备、存档副本迁移检查、停机备份后切换、启动验收及代码回退；程序版本保留在 releases，账号与城市数据保留在外置 SQLite。具体步骤见 [安全更新流程](docs/ACCOUNTS-AND-UPDATES.md)。

**简化宝塔更新：** 将最新 `deploy/baota/update.sh` 上传到 `/www/bayside-city/update.sh`。以后上传新包到 uploads，运行 `bash /www/bayside-city/update.sh` 完成准备后，向导保存进度并退出；去宝塔停止项目，再运行同一命令完成备份和切换；去宝塔启动项目，再运行同一命令验收。每个阶段之间可关闭终端，不需要保持原会话或按回车续接。旧版外层向导锁不影响新版入口，底层更新操作仍互斥。

名胜天际线与夜景：东方明珠、广州塔、帝国大厦、埃菲尔铁塔一级高度约为原来的 1.8 倍，二、三级继续提高到 2.05 / 2.3 倍；大本钟采用更低的 1.45 / 1.65 / 1.85 倍高度，较上一版整体降低约 20%。本地名胜也随修缮提高。东方明珠的球体和大本钟钟面保持比例；东方明珠与广州塔采用青色、粉色轮廓灯，埃菲尔铁塔和大本钟采用暖金结构灯，帝国大厦突出退台和塔冠。本地名胜有灯室、檐口与屋顶照明，二三级增加庭院灯和基座灯带。灯光随昼夜平滑亮起，暂停建筑关闭专属装饰灯，旋转后仍贴合模型。

埃菲尔铁塔模型采用四座外展、向内弯曲的独立桁架塔腿，底部四面拱门保持通透，两层主要平台位于塔身下部，上部连续收细至顶部观景室与天线。平台加入中央开口、栏杆和展厅，金色灯带沿塔腿、拱门、平台边缘和上段主梁布置。三个名胜等级与四个旋转方向共享该模型，仍保持在 3×3 地块内。
