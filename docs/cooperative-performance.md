# 合建城市操作延迟优化

合建服务器使用后台 Worker 计算城市进展和建设结果，建设任务优先于同城周期模拟。数据库提交仍在主线程完成，并检查城市版本、建设冲突、权限与重复请求；过期的模拟结果会丢弃。

操作确认响应同时返回已提交的城市状态和画面路线，客户端无需再等待一次完整状态请求。旧服务器仍使用原有拉取流程。

本版本需要更新并重启服务器，再刷新客户端页面。只刷新页面不会启用服务器后台计算。

本地使用 Megatron 的导出副本验证，不修改线上城市。后台计算避免堵住其他请求，但大型城市建设仍需要完成模拟计算，不能保证即时确认。

## 协作影子

合作成员的指针、名字、当前工具和半透明建设范围约每 500 毫秒同步一次。影子只表示对方的规划；实际建设以服务器确认的城市状态为准。预览最多显示 256 格。

位置使用独立轻量接口，不改变城市版本、资金、建设日志或撤销记录，也不会写入存档。只有同城合作成员能查看；关闭城市、隐藏页面、打开弹窗、断线、成员移除或恢复城市后会清除旧位置。断线位置最多保留约 5 秒。旧服务器不支持时自动关闭影子同步，建设流程可继续使用。
